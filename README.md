# SAMPLE: technical due diligence report and checklist

> **Illustrative sample on a fictional company. No client relationship. Not based on any real engagement or confidential material.** Prepared by Kunjar Bhaduri (Bhaduri Advisory), October 2, 2026, with AI drafting assistance under my direction.

## What it is
- `TDD_SAMPLE_REPORT.md`: a short buy-side technical due diligence report on an invented company, in the format I'd hand an investment committee: one-page Red/Amber/Green summary, findings tied to evidence and value, what was *not* found, a 100-day plan, and method and limits.
- `TDD_CHECKLIST.md`: the reusable checklist behind it (architecture, code and delivery, reliability, security, data, AI components, team).

## Which bids it answers
Technical due diligence work for private equity and growth investors, and fractional CTO roles that include preparing a company for investor technical review.

## How to use it
Read the report first (5 minutes). The checklist is meant to be copied and adapted per deal.

## Limits
Every finding and number is invented. Ratings are judgments, not an audit opinion or certification. No penetration test is implied.
